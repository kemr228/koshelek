# Кошелёк

Простой трекер расходов и доходов. Без аккаунта, без рекламы, данные хранятся только на телефоне.

## Структура

| Папка | Что это |
|---|---|
| `web/` | само приложение: HTML/CSS/JS без сборки и зависимостей. Ставится на iPhone как PWA («На экран Домой»), раздаётся с GitHub Pages |
| `native/` | обёртка Capacitor: то же приложение, упакованное в настоящее iOS-приложение (`.ipa`) |
| `.github/workflows/` | автоматическая сборка `.ipa` на macOS-раннере GitHub |

## Установка на iPhone

Подробная пошаговая инструкция — в [docs/ustanovka-iphone.md](docs/ustanovka-iphone.md). Коротко:

### Вариант 1: PWA — быстро и бесплатно

1. Открой адрес приложения (например `https://<user>.github.io/koshelek/`) в **Safari**.
2. Кнопка «Поделиться» → **«На экран Домой»**.
3. Готово. Приложение открывается без адресной строки, работает офлайн и обновляется само.

### Вариант 2: настоящее приложение — бесплатно, но с переподписью

1. В GitHub: Actions → «Собрать unsigned IPA» → Run workflow.
2. Скачай артефакт `koshelek-unsigned.ipa`.
3. На компьютере с Windows: [Sideloadly](https://sideloadly.io/) + кабель → введи свой Apple ID.
   Подпись бесплатного Apple ID живёт **7 дней**, потом повтори пункт 3.

### Вариант 3: с сертификатом разработчика ($99/год)

Подпись на год, TestFlight, App Store. Для себя и друзей обычно хватает варианта 2.

## Обновления

Поправил что-то в `web/` → push в GitHub:

- PWA обновится сама при следующем открытии (после поднятия `VERSION` в `web/sw.js`);
- для `.ipa` перезапусти workflow и переподпиши через Sideloadly.
