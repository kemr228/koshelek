# Как поставить «Кошелёк» на iPhone

Три способа: от самого быстрого до самого «настоящего». Начать можно с первого, а потом перейти на любой другой — данные переносятся через «Ещё → Сохранить копию».

---

## Способ 1. PWA — быстро, бесплатно, навсегда

1. В **Safari** (именно Safari, не Chrome и не Telegram-браузер) открой адрес приложения, например `https://kemr228.github.io/koshelek/`.
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»** → «Добавить».
4. На рабочем столе появится иконка. Приложение открывается на весь экран, работает офлайн и обновляется само.

Плюсы: 0 ₽, без Apple ID, без компьютера, обновления автоматические.
Минусы: нет App Store, нельзя push-уведомления (в рамках PWA).

---

## Способ 2. Настоящее приложение (.ipa) — бесплатно, но переподпись раз в 7 дней

### Шаг 1. Скачать .ipa

1. Открой репозиторий на GitHub → вкладка **Actions**.
2. Слева выбери **«Собрать unsigned IPA»** → **Run workflow** → подтверди.
3. Дождись зелёной галочки (~3–6 минут, сборка идёт в облаке на Mac).
4. Внизу в **Artifacts** скачай `koshelek-unsigned-ipa` → распакуй zip → внутри `koshelek-unsigned.ipa`.

### Шаг 2. Подготовить Windows (один раз)

1. Установи **iTunes** и **iCloud** с сайта apple.com
   ([iTunes](https://www.apple.com/itunes/download/win64), [iCloud](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe)).
   Именно с сайта — версии из Microsoft Store не ставят нужные драйверы, и Sideloadly не увидит телефон.
2. Скачай и установи **Sideloadly** с официального сайта **sideloadly.io**.

### Шаг 3. Установить

1. Подключи iPhone кабелем, разблокируй, на телефоне подтверди **«Доверять этому компьютеру»**.
2. Запусти Sideloadly. В поле **Apple ID** введи свой Apple ID (лучше отдельный, запасной).
3. Перетащи `koshelek-unsigned.ipa` в окно программы → нажми **Start** → введи пароль Apple ID.
4. На телефоне: **Настройки → Основные → VPN и управление устройством →** найди свой профиль → **Доверять**.

Готово: на рабочем столе обычное приложение.

### Через 7 дней

Бесплатная подпись Apple живёт ровно 7 дней, потом приложение перестаёт открываться. Нужно повторить Шаг 3 (телефон к компьютеру + Sideloadly).

Если лень повторять: **SideStore** ставится один раз и продлевает подпись сам, без компьютера — но настройка чуть муторнее.

### Если Sideloadly не видит телефон

- iTunes/iCloud стоят именно с apple.com, а не из Microsoft Store;
- кабель передаёт данные (многие — только зарядка);
- на телефоне нажато «Доверять этому компьютеру»;
- перезапусти комп и перевоткни кабель.

## Способ 3. Без переподписи — сертификат разработчика ($99/год)

Покупаешь Apple Developer Program ($99/год) → приложение грузится в **TestFlight** → ставишь из App Store, подпись живёт год, можно раздать друзьям (до 10 000 человек).

Из России оплата — самое больное место: карты РФ не проходят, нужна зарубежная карта или посредник. Для личного использования обычно хватает Способа 2.
