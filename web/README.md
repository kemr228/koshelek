# Кошелёк

Простой трекер расходов и доходов. Одно приложение, без аккаунта, без интернета:
все данные лежат в памяти телефона (localStorage).

## Что умеет

- записывать расход и доход: сумма, категория, комментарий, дата;
- показывать остаток за месяц и итоги по доходам и расходам;
- разбивать траты по категориям с процентами и полосками;
- переключаться между месяцами;
- работать офлайн и ставиться на домашний экран iPhone;
- сохранять и загружать резервную копию в JSON.

## Как устроено

Никакой сборки и зависимостей — обычные файлы, которые отдаёт любой статический хостинг.

```
index.html            разметка трёх экранов и нижней шторки
styles.css            оформление, светлая и тёмная тема автоматически
app.js                вся логика: хранение, отрисовка, экспорт/импорт
manifest.webmanifest  описание PWA для установки на телефон
sw.js                 service worker: офлайн-режим и обновления
icons/                иконки (генерятся скриптом)
tools/                служебные скрипты для разработки
```

Данные лежат в `localStorage` под ключом `wallet.db.v1`:

```json
{
  "v": 1,
  "currency": "RUB",
  "items": [
    { "id": "abc", "type": "expense", "amount": 350, "cat": "food",
      "note": "Пятёрочка", "date": "2026-11-22", "ts": 1732270000000 }
  ]
}
```

## Как поменять

**Добавить категорию** — массив `CATS` в начале `app.js`. Нужны `id`, `name`, `emoji`, `color`.

**Поменять валюту** — массив `CURRENCIES` там же, либо прямо в приложении: «Ещё» → «Символ валюты».

**Поменять цвета и отступы** — переменные в начале `styles.css`. Тёмная тема — блок
`@media (prefers-color-scheme: dark)`.

**Выпустить обновление** — подними `VERSION` в `sw.js` (например, `1.0.1`).
Тогда у всех, кто уже поставил приложение, подтянется новая версия.

## Локальный запуск

```powershell
# из папки wallet
python -m http.server 8788
# открыть http://127.0.0.1:8788
```

## Скриншоты для проверки вёрстки

```powershell
powershell -ExecutionPolicy Bypass -File tools/shots.ps1
```

Рендерит экраны через headless Edge в `_shots/` (нужен запущенный сервер на 8788).

## Иконки

```powershell
python tools/make-icons.py
```

## Установка на iPhone

1. Открыть адрес приложения в **Safari** (именно Safari, не Chrome).
2. Кнопка «Поделиться» → **«На экран Домой»**.
3. Готово: иконка на домашнем экране, приложение открывается без адресной строки.

Важно: адрес должен быть постоянным. Если открыть приложение по временной ссылке,
после её смерти данные останутся в памяти телефона, но обновиться приложение не сможет.
